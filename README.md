## 🔭 What I'm working on

- **[OpenSolaris on AArch64](https://github.com/moralesresearch/opensolaris)**: porting the OpenSolaris kernel to 64-bit ARM. It boots under QEMU `virt` (including 4-CPU SMP), with a `page_t`-backed HAT and GICv3 support, and GitHub Actions builds and smoke-tests every bootstrap image.
- **[voltOS](https://github.com/abdonmorales/voltOS)**: my own operating system project.
- **[lc3-vscode](https://github.com/abdonmorales/lc3-vscode)**: LC-3 assembly tooling for VS Code.
- **[artix7-clock](https://github.com/abdonmorales/artix7-clock)**: a digital clock on an Artix-7 FPGA.
